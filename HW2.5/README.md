## Ключевые компоненты

SyntheticDataGenerator

    Инициализирует Stable Diffusion pipeline

    Загружает ControlNet модель (Canny edges)

    Генерирует синтетические изображения с использованием классовых подсказок

    Сохраняет результаты в PNG

ImbalancedCIFAR10Dataset

    Создает искусственный дисбаланс классов

    Удаляет 90% класса "cat" для имитации редкого класса

    Используется для базовой тренировки

AugmentedCIFAR10Dataset

    Комбинирует оригинальный датасет с синтетическими изображениями

    Динамически загружает синтетику из директории

    Применяет трансформации для обеих групп изображений

Trainer

    Полный цикл обучения: train, evaluate, schedule

    Отслеживает accuracy и balanced accuracy

    Использует AdamW оптимизер с cosine annealing
